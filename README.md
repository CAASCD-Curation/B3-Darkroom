# 暗房 / VISUAL DATABASE

一个视觉研究档案网站——像一个可以翻看的卡片暗房，用来收藏、检索和组合研究过程中的视觉词条。

## 是什么

「暗房」是一个静态网页式的视觉数据库。每条词条以卡片形式呈现（正面为图像，背面为出处、年份、标签与备注），支持按分类浏览、按标签筛选、关键词搜索，以及自定义分组，把词条组织成自己的研究线索。

## 分类

| 分类 | 名称 | 说明 |
|------|------|------|
| A | ART / 经典艺术档案 | 经典艺术作品中的视觉案例 |
| B | LITERATURE / 文学意象 | 文学文本中的意象与场景 |
| C | SOCIAL / 社会素材 | 社会现象、事件与流行文化素材 |
| D | FORM / 形式灵感 | 形式、构成与视觉语言层面的灵感 |

目前共收录 126 个词条。

## 功能

- **分类浏览** — 顶部切换四个分类或查看全部
- **关键词搜索** — 匹配词条名 / 出处 / 标签 / 备注 / ID
- **标签筛选** — 点击标签墙交叉筛选
- **自定义分组** — 将词条加入多个组，形成研究线索；数据保存在本机浏览器（localStorage）
- **卡片交互** — 点击卡片翻面查看详细信息

## 使用

纯静态站点，无需构建。直接用浏览器打开 `index.html` 即可；或在本目录起一个简单的本地服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 目录结构

```
暗房-Darkroom/
├── index.html      # 页面结构
├── style.css       # 样式
├── app.js          # 交互逻辑（渲染、搜索、筛选、分组）
├── data.js         # 词条数据（由脚本生成，请勿手改）
├── assets/         # 卡片图像（按 A / B / C / D 分类存放）
└── materials/      # 素材来源
```

## 数据说明

`data.js` 为自动生成文件，请勿手改；如需增删或修改词条，请更新 Excel / assets / materials 源文件后重新运行生成脚本。
